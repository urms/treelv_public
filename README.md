# treelv_public
Open Source Module für Odoo von TreElv

## Positionsnummer · Modul order_posno

Dieses Modul erweitert die Verkaufsaufträge um eine Positionsnummer, eine Konfiguration für die Schrittweite und einen eigenen View, der erlaubt bestimmte Positionen neu zu nummerieren.
Kompatibel mit Odoo v18 / Community Edition. 

### Smybol Raupe

Das ist eine kleine Hommage an die Heimatstadt Hildesheim, in der die Raupe Nimmersatt für den deutschen Markt veröffentlicht wird. Da die Raupe sich nicht nur durch zig Lebensmittel frisst, sondern auch die Tage zählt, fügt sich das harmonich in das TreElv-Ökosystem von Odoo Apps und Modulen.
